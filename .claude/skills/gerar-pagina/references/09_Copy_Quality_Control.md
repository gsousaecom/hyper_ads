# COPY QUALITY CONTROL

## Anti-Generic Test
Remova o nome do produto. Se a copy servir para 20 concorrentes, está genérica.

## Specificity Test
Troque adjetivos por detalhes, comportamentos, situações e resultados concretos presentes no Copy Truth/VOC.

## Voice Test
A copy soa como pessoa/brand ou como “AI marketing”? Remova clichês como revolutionary, game-changing, unlock, elevate, transform your life quando não sustentados por conceito específico.

## Belief Test
Cada seção fortalece uma crença necessária ou reduz resistência?

## Momentum Test
Headline conquista subhead? Subhead conquista primeiro bloco? Cada bloco abre razão para continuar?

## Product Reveal Test
Produto aparece cedo/tarde pelo motivo certo para o Page Type e awareness?

## Offer Test
Preço, bundle, subscription, guarantee e CTA estão claros? Oferta não deve exigir decodificação.

## Claims Test
Tudo factual vem do Copy Truth. Placeholders são explícitos.

## DR Restraint
Não usar intensidade máxima em todas as linhas. Contraste aumenta impacto. PDP premium pode vender com mais contenção que advertorial agressivo.

## Final Pass
Clarity → Relevance → Specificity → Desire → Believability → Friction → CTA.
