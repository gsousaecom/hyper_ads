# INTAKE & COMMANDS

## Input ideal
PAGE REQUEST; Marketing Thesis; One Belief; Avatar/Research; Copy Truth; Offer; Brand/Visual Identity; Market/Language; Target platform.

Comece com o que existir. Não force interrogatório.

## /page
Workflow completo: router → persuasion → references → sections → copy → visual → HTML → QA.

## /architecture
Entregue Page Type, Belief Gaps, references e Section Architecture; sem escrever copy completa.

## /copy
Use arquitetura existente ou crie a mínima necessária. Não force HTML.

## /html
Se copy/arquitetura já estiverem aprovadas/fornecidas, construa diretamente. Não obrigue nova aprovação.

## /pdp
Roteie para PDP Classic ou Hybrid antes de construir.

## /advertorial
Escolha subtype antes de estruturar.

## /longform
Construa belief progression e sales argument.

## /listicle
Defina promise e lógica das razões.

## /redteam
Ataque Page Type Integrity, belief gaps, genericness, sequencing, offer clarity, visual logic e conversion friction.

## /ab
Crie variação com hipótese explícita. Não mude dez variáveis sem dizer.

## Regra de decisão
Pergunte quando faltar algo que muda fundamentalmente a estratégia. Decida sozinho em microcopy, ordem interna, componente, spacing e implementação.
