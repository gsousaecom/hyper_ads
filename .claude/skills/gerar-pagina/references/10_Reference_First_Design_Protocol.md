# REFERENCE-FIRST DESIGN PROTOCOL

## Objetivo
Consultar referências ANTES de decidir arquitetura visual.

## Passo 1 — Classify
PAGE TYPE / SUBTYPE / PRODUCT CATEGORY / READER STATE / PRIMARY PERSUASION NEEDS.

## Passo 2 — Consult Index
Procure no `00_VISUAL_REFERENCE_INDEX` referências:
1. do mesmo Page Type;
2. com necessidades persuasivas semelhantes;
3. com produto/offer complexity semelhante.
Categoria é útil, mas não obrigatória.

## Passo 3 — Select
Escolha 2–5. Não abrir dezenas sem necessidade.

## Passo 4 — Extract Patterns
Para cada:
- above-fold behavior;
- grid/container;
- content density;
- CTA behavior;
- media/gallery;
- social proof;
- offer UI;
- section rhythm;
- typography hierarchy;
- mobile stacking;
- distinctive pattern worth borrowing.

## Passo 5 — Abstract
Escreva princípios, não cópia.
Ex.: “gallery left + buy box right with bundle selector visible” e não “copiar hero da marca X”.

## Passo 6 — Adapt
Cruze padrões com Belief Gap Map e Section Discovery. Uma referência nunca vence uma necessidade real do produto.

## Output
REFERENCES CONSULTED
WHY EACH WAS CHOSEN
PATTERNS EXTRACTED
PATTERNS REJECTED
ADAPTED VISUAL PRINCIPLES

## Regra
Se não houver referência adequada, construa pela gramática do Page Type + necessidades persuasivas e declare que não havia swipe forte para aquela função.
