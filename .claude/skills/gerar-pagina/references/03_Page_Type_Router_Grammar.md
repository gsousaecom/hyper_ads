# PAGE TYPE ROUTER & GRAMMAR
Page Type define comportamento; Product + Thesis + Reader State definem seções.

## PDP Classic Shopify/DTC
Product media + commerce/buy area + preço/variant/bundle quando aplicável + CTA + informações críticas. Compra deve ser resolvível rapidamente. Persuasão posterior é dinâmica. Não virar automaticamente long-form.

## PDP Hybrid / Sales-Heavy
Preserva commerce UX de PDP, mas aceita argumento longo quando novidade, ticket ou resistência exigem.

## Advertorial
Presell editorial. Headline/dek, narrativa/argumento contínuo, produto como consequência. Subtypes: discovery, investigative, confessional, expert, story, native/news.

## Listicle
Sequência escaneável de razões. Cada item adiciona nova persuasão. Subtypes: reasons why, mistakes, signs, comparisons, best-of.

## Long-Form Sales Page
Argumento completo: lead → belief progression → solution/product → offer. CTAs conforme progressão.

## VSL Page
Vídeo é centro; supporting copy serve play/completion/action.

## Landing/Campaign Page
Defina conversion event: lead, single offer, launch, collection etc.

## Upsell/Downsell
Continuidade pós-compra, uma proposta, relevance bridge, baixa distração, accept/decline claros.

## Homepage
Posiciona/orienta/distribui tráfego; não tratar automaticamente como sales page.
